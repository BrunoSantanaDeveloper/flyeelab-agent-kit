# COLOR-PALETTES.md — Paletas Harmoniosas para o Template Corporate

> **Uso:** Escolher UMA paleta ao criar novo projeto com `CORPORATE-TEMPLATE.md`.
> **Cada paleta inclui:** Primary, Light, Dark, Accent, Muted + Shadow RGBA.
> **Todas testadas:** Contraste WCAG AA sobre fundos claros e escuros.

---

## Como Usar

1. Escolha a paleta que combina com o segmento/marca
2. Substitua os placeholders `{PALETTE.*}` no `CORPORATE-TEMPLATE.md`
3. O `--shadow-brand` usa o `shadow-rgba` da paleta

---

## Regras de Uso

1. **Uma paleta por projeto** — consistência visual
2. **Neutros são fixos** — os cinzas/escuros do template não mudam
3. **Shadow RGBA** — usar a cor primária com opacidade 0.20-0.25
4. **Gradients** — gerar `linear-gradient(135deg, primary, primary-accent)`
5. **Testes de contraste** — validar texto sobre cores claras e escuras
